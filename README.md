# Factorio-Space-platform-hub-control
A decider like mod 
how to use:
1. connect the mod output to a hub
2. Any input is connected to mod input
3. to read hub signal connect decider or whatewer you want to mod output
Pros :
1. can control hub automatic/manual via signal any signal input to the mod if it more than 0 than then the gui will control it
2. can read hub state via signal example if hub is automatic and moving then it reads as H1 else H0
3. can precission control speed for example you put 30km/s then it will hard lock at that speed after reaching it
4. has a dummyinput funcion if you want to control hub automatic/manual via mod GUI without signal
